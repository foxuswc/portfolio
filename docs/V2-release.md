# 个人作品集 V2.0 · 2026-11-23

基于原有 main 分支升级，保留个人照片、RA Studio 长案例与原交互示意、DemandLoop 概念资料。部署仍由原 Render 服务从 GitHub main 触发。

## 页面与功能

- `index.html`：首页定位、三个真实项目入口、产品方法、经历、简历与邮箱；DemandLoop 移至折叠的次级探索。
- `ra-studio.html`：沿用原案例，补充六张原有产品原型、AI 职责分工、简历成果与统计边界。
- `sellerlab.html`：新案例；真实历史指标拆解、四类诊断路径、规则 / Agent 分工、离线对照与失败分析。
- `membership-ai.html`：新案例；用户 / 运营双端、规则基线、资格与费用、增长实验方案。
- `assets/home.css`、`assets/case-original.css`：从原 HTML 拆出的原始设计系统。
- `assets/v2.css`：统一蓝白视觉与所有响应式修正；Seller Lab 橙色、会员项目暖金。
- `assets/site.js`：手机目录、项目切换、原图 / 适应屏幕、上一张 / 下一张、键盘和触摸浏览、原焦点恢复。
- `scripts/check_site.py`：资源、链接、锚点、重复 ID、定位文案、viewport、JS 语法检查。

首页 HTML 从 4,120,409 字节缩小至18,652 字节（约 18.7KB）；内嵌照片改为独立 WebP，封面使用 24—40KB 预览，案例保留原尺寸截图，按需加载。无构建工具或额外前端依赖。

## 测试记录

Chrome 实际浏览器：通过同源 iframe 构成 24 个独立页面视口，宽度分别为 320、375、390、430、768、1440px，覆盖首页及三个案例。每一页面的 documentElement.scrollWidth 与 clientWidth 相等，无页面横向滚动；表格在自己的容器内滚动。检查 320、390、768px 下正文、按钮、标题与图片边界，未发现非预期裁切。

实际点击通过：

- 手机菜单打开 / 关闭；从首页分别进入三个独立案例。
- RA / Seller Lab / Membership 截图放大、下一张、原图尺寸、Escape 关闭及焦点返回。
- Seller Lab 四类诊断标签切换。
- 手机目录与项目切换入口；PDF 简历与邮箱为真实链接。
- Seller Lab 公网：巡检 → 已完成报告 → SQL 证据抽屉。
- Membership 公网：生成消费方案 → 确定性金额与预算 → 策略总览 → 规则配置。
- 静态链接及全部 JS 语法检查、git diff --check 通过。

浏览器扩展自身存在 metadata 日志错误，不属于网站脚本；没有把扩展日志算为页面故障。

局限：尚无 iPhone Safari / Android Chrome 真机及扫码实测，不将 Chrome 响应式测试表述为真机验收。免费 Demo 实例会休眠，首次打开需要等待。生产部署与宽度复核另以交付时实际结果为准。
