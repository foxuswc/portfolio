# Portfolio hosting

Primary URL: https://devy-vq21.onrender.com/

The original https://portfolio-ujn3.onrender.com/ remains available so existing resume QR codes and shared links keep working. Both static services deploy the `main` branch of `foxuswc/portfolio`.

- `portfolio` (original): Blueprint-managed by `render.yaml`; keep its name and configuration intact.
- `devy` (primary): created in the Render Dashboard on 2026-11-23, build command `echo "Static site ready"`, publish directory `.`, auto-deploy on commits.

All four portfolio HTML pages use the purple Devy D favicon. Browser exports are SVG, a 32px PNG, a multi-size root ICO, and a 180px Apple touch icon. The independent SellerLab and Membership AI repositories contain their own orange and gold icon sets. Membership AI retains its existing manual deployment configuration.
